# 任务 6：文本生成实验报告

本任务完成了项目中的两个 T5 生成示例：基于文章和问题生成答案（`qa`），以及根据带 `[MASK]` 的句子生成缺失片段（`filling`）。统一入口为 [`run_generation.py`](./run_generation.py)，提供 `train`、`evaluate`、`predict` 三种模式。

## 模型与数据

使用 `uer/t5-small-chinese-cluecorpussmall` 中文预训练模型。原项目示例使用 T5-base；本次选用 T5-small，以便在本机 RTX 5080 16 GB 上完成两项实际训练。模型文件放在 `answer_generation/models/t5-small-chinese-cluecorpussmall`，训练输出位于 `text_generation/runs/`，两处均被 Git 忽略。训练采用 AdamW、固定种子 42、batch size 32，并按验证集字符 F1 保存最佳检查点。该模型的 tokenizer 采用 BERT 特殊符号：解码从 `[CLS]` 开始，以 `[SEP]` 结束；填充标签使用 `-100` 忽略损失。

| 任务 | 原始训练行 | 原始开发行 | 清理后训练行 | 从开发集剔除与训练集重合的行 | 实际训练行 | 验证行 | 测试行 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 生成式问答 | 14,520 | 984 | 14,520 | 56 | 14,520 | 256 | 463 |
| 片段补全 | 350,136 | 38,904 | 348,123 | 279 | 第一阶段 20,000；第二阶段 100,000 | 256 | 512 |

清理会跳过空字段、格式错误以及补全任务中 `[MASK]` 数量不符合格式的行。问答按 `context`、补全按完整带遮盖的 `source` 分组，先去除与**完整训练集**重叠的开发集样本，再拆分验证与测试，同一分组不会跨集合。开发集样本远多于本次评估上限，脚本保留可复现的固定种子采样；未采样的开发集样本不参加训练或评估。片段补全的训练集较大，本次采用分阶段训练，报告成绩只代表所用的 10 万训练样本，并非全量 348,123 行训练成绩。

## 测试结果

| 任务与检查点 | 独立测试数 | 完全匹配率 | 字符 F1 | 字符 BLEU-4（加一平滑） |
|---|---:|---:|---:|---:|
| 生成式问答，4 epoch | 463 | 31.53% | 63.34% | 48.77% |
| 片段补全，20,000 行 × 4 epoch | 512 | 2.93% | 20.27% | 2.93% |
| 片段补全，续训至 100,000 行 × 3 epoch | 512 | 4.49% | 29.27% | 8.23% |

完全匹配率与字符 F1 会去除空白字符；问答还会去除生成文本开头的 `答案：`。BLEU-4 是脚本实现的**字符级语料指标，采用加一平滑**，不能直接与原项目示例或其他分词、平滑方式的 BLEU 数值比较。模型由验证集字符 F1 选取，表中测试数据只在训练结束后用于最终评估。

问答测试示例：当输入文章中写有“报雅思或者托付培训班，一般情况下要900元左右”并询问“雅思班价格”时，模型和参考答案均为“900元左右”。存在错误样本，例如原文更推荐“极点五笔”，模型却生成“王码五笔”。

补全比短答案问答难得多，缺失片段可能包含无法仅凭上下文确定的日期、姓名等细节。在 512 条测试样本中，有 3 条输入超过 128 token、11 条目标超过可用于正文的 47 token；截断也会影响这些样本的评估。模型还可能重复生成或凭空补写。因而补全结果适合作为可运行的实验基线，使用于 UIE 数据增强时仍需人工或规则过滤生成片段。

重新加载保存的检查点后，独立执行 `evaluate` 得到了与表格一致的结果。`predict` 命令也已验证：上述雅思班示例输出“900元左右”；补全输入 `"歌曲[MASK]是由歌手海生演唱的一首歌曲"中[MASK]位置的文本是：` 时输出“《我的爱情》”，这是生成候选而非已验证的原文。

## 复现

以下命令在仓库根目录执行，`python` 应指向含 PyTorch、Transformers、NumPy、Hugging Face Hub 的环境。先从 Hugging Face 下载预训练模型；也可在训练时用 `--model uer/t5-small-chinese-cluecorpussmall` 指定模型 ID，由 Transformers 下载。模型下载需联网，此后的训练、评估和推理可离线运行。

```powershell
python -c 'from huggingface_hub import snapshot_download; snapshot_download(repo_id="uer/t5-small-chinese-cluecorpussmall", local_dir="answer_generation/models/t5-small-chinese-cluecorpussmall")'

python text_generation/run_generation.py train --task qa --epochs 4 --patience 2 --batch-size 32 --eval-batch-size 32 --max-valid 256 --max-test 512 --output-dir text_generation/runs/qa
python text_generation/run_generation.py evaluate --task qa --output-dir text_generation/runs/qa
python text_generation/run_generation.py predict --task qa --output-dir text_generation/runs/qa --question "雅思班价格" --context "报雅思或者托福培训班，一般情况下要900元左右。"

python text_generation/run_generation.py train --task filling --epochs 4 --patience 2 --batch-size 32 --eval-batch-size 32 --max-train 20000 --max-valid 256 --max-test 512 --output-dir text_generation/runs/filling
python text_generation/run_generation.py train --task filling --model text_generation/runs/filling --epochs 3 --patience 2 --batch-size 32 --eval-batch-size 32 --max-train 100000 --max-valid 256 --max-test 512 --learning-rate 5e-5 --output-dir text_generation/runs/filling_100k
python text_generation/run_generation.py evaluate --task filling --output-dir text_generation/runs/filling_100k
python text_generation/run_generation.py predict --task filling --output-dir text_generation/runs/filling_100k --masked-text '"歌曲[MASK]是由歌手海生演唱的一首歌曲"中[MASK]位置的文本是：'

python -m unittest discover -s text_generation -p test_generation.py -v
```

每个检查点内的 `metrics.json` 记录数据清理数量、训练曲线、最佳 epoch、验证与测试指标及预测样例。训练脚本也可省略 `--max-train` 使用全部训练数据；本报告的指标不代表全量训练结果。
