# 任务 7：大模型应用实验报告

本任务完成了原项目第 7 节的四项应用：文本分类、文本匹配、信息抽取和大模型 MBTI 问卷。新入口为 [`run_llm_application.py`](./run_llm_application.py)。原 `zero-shot` 目录中的 ChatGLM-6B 示例保留；本次实际运行使用 [Qwen2.5-1.5B-Instruct 模型](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct)，它提供 Transformers 聊天模板，可在本机 16 GB 显存环境加载。两种模型的结果不应直接比较。

## 方法

前三项使用真正的 zero-shot 提示：只提供任务规则、候选标签或字段结构，不在提示中放带答案的示例。分类在“人物、书籍、电视剧、电影、城市、国家”中选择；匹配在“相似、不相似”中选择；抽取先判断人物、书籍或电视剧类型，再按照该类型的字段结构生成 JSON。生成过程使用贪心解码，结果必须通过 JSON 和标签、字段校验；不符合结构的输出计为无效。所有案例、模型原始回复、解析结果和指标写入 `LLM/runs/zero_shot.json`。

MBTI 使用仓库自带的 93 道 A/B 问卷。对每道题，不采样生成文本，而是比较聊天提示后下一个 token 为 `A` 或 `B` 的模型 logit，并按题库中的映射给 E/I、S/N、T/F、J/P 计数。第 75 题把 A 映射为 T、B 映射为 N，两个选项不属于同一维度，因此自动跳过；有效题共 92 道。结果、每题选择、选择概率和被跳过的题写入 `LLM/runs/mbti.json`。这是一种**提示下的模型输出倾向测量**，不是心理学意义上的人格诊断；更换措辞、选项顺序或模型都可能改变结果。

## 实际运行结果

| 任务 | 测试案例 | 指标 | 结果 |

| 文本分类 | 6 | 标签准确率 | 5/6 = 83.33% |
| 文本匹配 | 4 | 标签准确率 | 3/4 = 75.00% |
| 信息抽取 | 3 | 结构有效率 / 实体类型准确率 | 3/3 / 3/3 |
| 信息抽取 | 3 | 整条记录完全匹配率 | 1/3 = 33.33% |
| 信息抽取 | 3 | 字段值微平均 F1 | 11 个值命中，预测 13 个、参考 15 个；F1 = 78.57% |

分类将“加拿大首都渥太华”误判为“城市”；匹配将“如何修改头像”和“可以通过上传图片修改头像吗”判为“不相似”。抽取能够生成合法结构，但会遗漏“男”性别、将“演员”写成“男演员”，或省略电视剧题材。这些小规模手写示例只用于检查流程是否可运行，不能视为模型的通用性能基准。

MBTI 的 92 道有效题得到 **ENTJ**：E/I 为 14/7，S/N 为 10/16，T/F 为 15/8，J/P 为 16/6，无平票。已有的 [`web.py`](./llms_mbti/web.py) 可读取新运行结果进行展示；若新结果文件不存在，则展示仓库原有的静态示例数据。

## 复现

以下命令从仓库根目录执行，`python` 应指向包含 PyTorch、Transformers、Hugging Face Hub、NumPy 的环境。首次下载需联网，之后模型从 `LLM/models/Qwen2.5-1.5B-Instruct` 加载。模型和 `LLM/runs/` 输出均被 Git 忽略。官方模型卡展示了 `AutoModelForCausalLM` 和 `apply_chat_template` 的加载与推理用法。

```powershell
python -c 'from huggingface_hub import snapshot_download; snapshot_download("Qwen/Qwen2.5-1.5B-Instruct", local_dir="LLM/models/Qwen2.5-1.5B-Instruct")'

python LLM/run_llm_application.py zero-shot --task all
python LLM/run_llm_application.py mbti

python LLM/run_llm_application.py predict --task classification --text '《三体》是刘慈欣创作的科幻小说。'
python LLM/run_llm_application.py predict --task matching --text '如何修改头像' --text-b '如何更换个人头像'
python LLM/run_llm_application.py predict --task extraction --entity-type 书籍 --text '《三体》是刘慈欣创作的长篇科幻小说。'

python -m unittest discover -s LLM -p test_llm_application.py -v
python -m streamlit run LLM/llms_mbti/web.py
```

`predict --task extraction` 可以省略 `--entity-type`，让模型先自动分类。MBTI 调试可用 `--max-questions 5` 缩短运行时间；完整结果须省略该参数。独立预测已验证：上例分类输出“书籍”、匹配输出“相似”、抽取返回符合 schema 的书名、作者与类型。Streamlit 页面已使用 AppTest 加载本次结果，无运行异常。
