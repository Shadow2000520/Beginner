# 任务 8：大模型训练实验报告

本任务在当前单卡环境中完成了继续预训练、ShareGPT 指令微调、混合任务 LoRA 微调、偏好奖励模型和 PPO 的可运行训练链路。使用 [Qwen2.5-0.5B 基础模型](https://huggingface.co/Qwen/Qwen2.5-0.5B)；原项目的 OpenLlama-7B 与 ChatGLM-6B 脚本保留，**本次结果是同一训练方法的本地适配实验，不是这两个 6B/7B 模型的复现**。训练入口为 [`run_llm_training.py`](./run_llm_training.py)、[`run_llm_reward.py`](./run_llm_reward.py) 和 [`run_llm_ppo.py`](./run_llm_ppo.py)。

## 数据和训练方法

| 阶段 | 数据来源 | 实际训练 / 验证 / 测试 | 方法 |
|---|---|---:|---|
| 继续预训练 | MNBVC news、qa、wiki 示例 JSONL | 200 / 25 / 25 | 因果语言建模，LoRA rank 8，3 轮，最大 128 token |
| 指令微调 | ShareGPT 对话 JSONL | 1,024 / 64 / 64 | 接续预训练适配器，只在助手回复上计算损失，LoRA rank 8，3 轮，最大 192 token |
| 混合任务微调 | `chatglm_finetune/data` 分类与 SPO 抽取 | 902 / 61 / 61 | 接续前两个适配器，LoRA rank 8，3 轮，最大 256 token |
| 奖励模型 | `LLMsTrainer` 正负评论偏好对 | 900 / 100 / 100 | 接续预训练和指令适配器，训练最后一层解码器与标量奖励头，pairwise softplus 损失 |
| PPO | 商品评论续写提示 | 24 步 × 4 条续写；另用 6 个未见提示 × 4 次采样评估 | 从指令微调策略出发，使用上一步奖励模型、冻结参考策略、价值头和序列级裁剪 PPO |

预训练样本按全文去重和分组；ShareGPT 从每段对话提取首轮用户与助手交互，按用户提示分组后切分，完整训练部分有 8,713 条，本次固定种子采样 1,024 条。混合任务沿用仓库已有训练集和开发集，开发集按种子拆成验证与测试，训练与开发的 `context` 无重叠。奖励数据有 1,000 条训练池偏好对，留出其中 100 条验证；仓库另给出 100 条独立测试对，评论文本与训练池不重合。

三个生成阶段的 LoRA 只更新注意力 `q_proj`、`v_proj`；下一阶段先合并上一阶段的适配器，再训练新适配器。训练输出只保存适配器或可训练权重，不复制基础模型。预训练和指令微调的困惑度仅在各自目标 token 上计算；输入提示与填充 token 不计入指令微调损失。PPO 复用[任务 5 的序列级目标实现](../RLHF/run_ppo.py)，把整段 12-token 续写视为一个动作，因此不等同于逐 token PPO/GAE。

## 实测结果

| 阶段 | 训练前验证指标 | 最佳验证指标 | 独立测试指标 |
|---|---:|---:|---:|
| 继续预训练 | 困惑度 24.79 | 18.97（第 3 轮） | **17.20** |
| ShareGPT 指令微调 | 困惑度 9.69 | 8.64（第 2 轮） | **7.45** |
| 混合任务微调 | 困惑度 3.36 | 1.11（第 3 轮） | **1.09** |
| 奖励模型 | 偏好对准确率 60% | 96%（第 3 轮） | **97%**，100 对 |

各阶段的目标文本与长度不同，困惑度**不能跨行直接比较**。混合任务目标大量是短标签或固定 JSON 格式，因此低困惑度只说明该特定格式容易预测，不能推断通用问答或抽取准确率。独立重载检查点后，三个生成阶段的测试困惑度及奖励模型 97% 的测试准确率均已复现。

PPO 在训练提示上的平均归一化奖励由 **0.454 → 0.642**。对于未参与训练的 6 个提示，每个提示以相同随机种子采样 4 次，重载策略后的平均归一化奖励为 **0.414 → 0.440**，原始奖励均值为 -3.049 → -2.249。这 24 条续写仍由同一个奖励模型评分，样本量小，不能证明人工偏好或通用生成质量提升。

命令行生成检查：预训练模型续写“人工智能的发展”时有明显重复；指令模型回答自我介绍时仍有冗长罗列。混合任务模型对“苹果很甜，送货也快”生成 `["水果"]`；奖励模型给正面评论 11.625、负面评论 -14.938；PPO 模型对“刚收到货，感觉”生成“很满意，也很愉快，特别喜欢这款产品，非常”。这些例子显示链路可运行，也保留了小模型的质量局限。

## 复现命令

以下命令从仓库根目录执行。环境为 Python 3.11、PyTorch 2.13、Transformers 5.16、PEFT 0.21、Accelerate 1.15 和 RTX 5080 16 GB。模型可从 Hugging Face 下载到 Git 忽略的 `LLM/models/Qwen2.5-0.5B`；训练结果在 Git 忽略的 `LLM/runs/training/`。LoRA 训练遵循 [PEFT 官方配置方式](https://huggingface.co/docs/peft/main/en/tutorial/peft_model_config)。

```powershell
python -c 'from huggingface_hub import snapshot_download; snapshot_download("Qwen/Qwen2.5-0.5B", local_dir="LLM/models/Qwen2.5-0.5B")'

python LLM/run_llm_training.py train --stage pretrain --epochs 3 --batch-size 4 --max-length 128 --learning-rate 2e-4 --output-dir LLM/runs/training/pretrain
python LLM/run_llm_training.py train --stage sft --init-adapter LLM/runs/training/pretrain --epochs 3 --batch-size 8 --max-train 1024 --max-eval 64 --max-length 192 --learning-rate 2e-4 --output-dir LLM/runs/training/sft
python LLM/run_llm_training.py train --stage mixed --init-adapter LLM/runs/training/pretrain --init-adapter LLM/runs/training/sft --epochs 3 --batch-size 8 --max-length 256 --max-prompt-length 160 --learning-rate 2e-4 --output-dir LLM/runs/training/mixed
python LLM/run_llm_reward.py train --init-adapter LLM/runs/training/pretrain --init-adapter LLM/runs/training/sft --epochs 3 --batch-size 8 --max-length 96 --learning-rate 2e-5 --output-dir LLM/runs/training/reward
python LLM/run_llm_ppo.py train --init-adapter LLM/runs/training/pretrain --init-adapter LLM/runs/training/sft --steps 24 --batch-size 4 --ppo-epochs 2 --output-dir LLM/runs/training/ppo

python LLM/run_llm_training.py evaluate --stage pretrain --output-dir LLM/runs/training/pretrain --batch-size 4
python LLM/run_llm_training.py evaluate --stage sft --output-dir LLM/runs/training/sft --batch-size 8
python LLM/run_llm_training.py evaluate --stage mixed --output-dir LLM/runs/training/mixed --batch-size 8
python LLM/run_llm_reward.py evaluate --output-dir LLM/runs/training/reward --batch-size 8
python LLM/run_llm_ppo.py evaluate --output-dir LLM/runs/training/ppo --samples-per-prompt 4 --seed 123

python LLM/run_llm_training.py predict --stage sft --output-dir LLM/runs/training/sft --prompt "用户：你好，请用一句话介绍你自己。`n助手："
python LLM/run_llm_reward.py score --output-dir LLM/runs/training/reward --text '水果新鲜，包装完好，服务周到。' --text '水果发霉，包装破损，服务很差。'
python LLM/run_llm_ppo.py generate --output-dir LLM/runs/training/ppo --prompt '刚收到货，感觉' --seed 123

python -m unittest discover -s LLM -p test_llm_training.py -v
python -m unittest discover -s RLHF -p test_rlhf.py -v
```

训练脚本都支持 `--max-train`、`--max-eval` 等较小参数用于短程验证。报告中的正式指标来自上述训练规模。每阶段 `metrics.json` 记录数据数量、训练曲线、最佳轮次和测试结果，PPO 的 `metadata.json`、`heldout_eval.json` 保留奖励曲线及生成样例。
