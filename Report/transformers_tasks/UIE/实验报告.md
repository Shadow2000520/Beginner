# 任务 2：信息抽取（UIE）实验报告

本任务使用仓库的 UIE 起止位置抽取结构，完成了 DuIE 示例数据的训练、验证、独立测试和按 schema 预测。模型从本机已有的 `BAAI/bge-small-zh-v1.5` 中文编码器初始化，起止位置预测层重新训练。它是一个可运行的信息抽取实验，**不是** README 中从 `Pky/uie-base-zh` 加载的原版 UIE 权重；两者指标不能直接比较。

## 数据与评估方法

仓库提供 2,087 条训练样本（90 段原文）和 232 条验证样本（10 段原文），`test.txt` 为空。将原验证集保留为最终独立测试集，从原训练集的 90 段文本中按随机种子 42 留出 10 段作为验证，其余 80 段用于训练。划分后分别为训练 1,809 条、验证 278 条、测试 232 条样本，同一段原文不会跨集合出现。答案标注与分词器输入逐一核对，验证集和测试集没有截断或无法对齐的答案。具体数量及原文件校验值见 [数据审计](../../../transformers_tasks/UIE/runs/full/data_audit.json) 和 [对齐检查](../../../transformers_tasks/UIE/runs/full/alignment_audit.json)。

每条样本包含 `prompt`、`content` 和答案在原文中的字符位置。模型预测答案的开始与结束位置，用验证集选择概率阈值和最佳训练轮次。指标按**答案字符起止位置完全相同**计数，分别统计实体提示、关系提示及总体的精确率、召回率、F1。测试集仅在根据验证集选定模型后评估。

## 训练设置与增强实验

环境：Windows、Python 3.11.16、PyTorch 2.13.0+cu130、Transformers 5.16.1、RTX 5080。三组实验均从同一个本地 BGE-small-zh-v1.5 权重开始，训练 20 轮、批量大小 16、最大输入长度 256、学习率 5e-5、BF16 自动混合精度。

| 训练集方案 | 训练样本 | 最佳验证集 F1 | 最佳轮次 |
|---|---:|---:|---:|
| 原始数据 | 1,809 | 0.430 | 16 |
| 原始数据 + SwapSPO | 1,899 | **0.466** | 15 |
| 原始数据 + 难负例复用 | 2,109 | 0.449 | 14 |

SwapSPO 只从训练集中的单答案关系样本生成，替换同一关系下的主语、宾语，并验证新答案的字符位置，共得到 90 条。难负例实验先用基础模型对训练集里**已有标注的负例**打分，选出 150 条高风险关系负例并重复训练；这属于难例复用，不等同于生成全新标签的原 README“Auto Neg”。验证集表现最好的 SwapSPO 模型被选作最终模型。Mask Then Fill 需要额外训练的填充生成模型；本仓库没有提供其权重，因此本次没有运行该增强策略。

## 独立测试结果

| 类型 | 正确 / 预测 / 标注答案数 | 精确率 | 召回率 | F1 |
|---|---:|---:|---:|---:|
| 实体抽取 | 14 / 30 / 28 | 0.467 | 0.500 | 0.483 |
| 关系抽取 | 8 / 25 / 19 | 0.320 | 0.421 | 0.364 |
| **总体** | **22 / 55 / 47** | **0.400** | **0.468** | **0.431** |

最佳验证集阈值为 0.7，最终测试集包含 10 段原文、232 条提示样本。测试段落数量很少，结果对数据划分敏感。关系抽取的精确率尤其有限；在其他文本上使用前，应扩充标注并复验。

示例文本“谭孝曾是谭元寿的长子，也是谭派第六代传人。”的端到端结果：`人物 → 谭孝曾、谭元寿`；`谭孝曾的父亲 → 谭元寿`。逐条测试预测在 [test_predictions.json](../../../transformers_tasks/UIE/runs/full/test_predictions.json)，完整示例在 [demo.json](../../../transformers_tasks/UIE/runs/full/demo.json)。模型还接受实体类型列表或“主语类型 → 属性列表”的 schema。事件抽取可以使用同样的提示接口，但 DuIE 样例没有事件标签，本次没有事件抽取质量指标。

## 复现与预测

入口为 [run_uie.py](../../../transformers_tasks/UIE/run_uie.py)，回归检查为 [test_uie.py](../../../transformers_tasks/UIE/test_uie.py)。完整结果和模型权重保存在本机 `UIE/runs/full/`：每个方案的 `best/` 有 `uie.safetensors`、分词器和配置；`result.json`、`history.json` 与数据审计文件保存训练和评估信息。`runs/` 由 Git 忽略。

在项目根目录、具备 PyTorch、Transformers、NumPy、scikit-learn、safetensors 的 Python 环境中训练：

```powershell
$env:PYTHONUTF8 = '1'
$env:TOKENIZERS_PARALLELISM = 'false'
python UIE/run_uie.py train `
  --model E:\Workspace\Beginner\llm-beginner\task-4-rag\models\bge-small-zh-v1.5 `
  --local-only --output UIE/runs/new_run --amp
```

选择实体类型进行预测：

```powershell
python UIE/run_uie.py predict `
  --checkpoint UIE/runs/full/swap_spo/best `
  --content '谭孝曾是谭元寿的长子，也是谭派第六代传人。' `
  --schema '["人物"]'
```

先找人物，再抽取其父亲：

```powershell
python UIE/run_uie.py predict `
  --checkpoint UIE/runs/full/swap_spo/best `
  --content '谭孝曾是谭元寿的长子，也是谭派第六代传人。' `
  --schema '{"人物":["父亲"]}'
```

`--prompt` 也可用于单个问题，例如 `--prompt '谭孝曾的父亲'`。输出附带答案文本及原文起止位置。
